# 🍔 Zona Crunch - Landing Page Experience

![Estado del Proyecto](https://img.shields.io/badge/Estado-En%20Desarrollo-orange)
![Tech Stack](https://img.shields.io/badge/Stack-HTML5%20%7C%20CSS3%20%7C%20JS-brown)

**Zona Crunch** es una plataforma web moderna y visualmente impactante diseñada para un concepto de restaurante de comida rápida premium. El proyecto se enfoca en ofrecer una experiencia de usuario (UX) fluida, destacando productos mediante componentes interactivos y un diseño limpio.

## 🚀 Características Principales

- **Diseño UI/UX Moderno:** Uso de tipografías de alto impacto como *Anton* para títulos y *Poppins* para legibilidad.
- **Menú Interactivo (Flip Cards):** Los productos se presentan en tarjetas que giran al pasar el cursor (hover), revelando detalles como ingredientes y precios.
- **Header Dinámico:** Navegación optimizada y centrada con efectos de transición suaves.
- **Galería de Productos Realista:** Integración de imágenes organizadas por categorías (Hamburguesas, Perros, Pizzas y Salchipapas).
- **Responsive Design:** Adaptado para una visualización óptima en diversos dispositivos.

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica del sitio.
- **CSS3:** Estilizado avanzado utilizando variables (Custom Properties), Flexbox para el centrado del layout y animaciones para el efecto flip.
- **JavaScript (Vanilla):** Lógica para el filtrado de categorías en el menú y manejo de estados activos en los paneles.
